# SAFAR — Official Website & Interactive Telemetry Bench

Welcome to the official web portal and interactive simulation benchmark for **SAFAR** (Modular Road-Safety Intelligence for Existing Vehicles).

## 🚀 Live Preview / Local Hosting
To preview the website locally:

`ash
# Using Python 3 HTTP Server
python -m http.server 8000
`
Then open [http://localhost:8000](http://localhost:8000) in your browser.

## 🛠️ Tech Stack
- **HTML5 & CSS3**: Custom automotive AI design system (dark mode, glassmorphism, responsive grid).
- **Vanilla JavaScript**: Interactive 5-scenario HUD simulator with live telemetry diagnostics and scroll animations.
- **Vector Assets**: Custom SAFAR S-Shield perception emblem.
